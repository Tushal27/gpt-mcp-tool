One-time setup

This build has no Supabase credentials yet, so there is nowhere to sync to.

  1. Create a free project at supabase.com.
  2. SQL Editor → paste supabase/schema.sql from this repo → Run.
  3. Project Settings → API → copy the Project URL and the anon / publishable key.
  4. Paste both into config.js, commit, redeploy.
  5. Authentication → URL Configuration → add your site URL to Redirect URLs.

Both values are safe to commit publicly. Row Level Security is what protects your data, and the schema above enables it.
